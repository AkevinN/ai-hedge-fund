# 国内数据系统接入测试验证计划

## 1. 测试目标

验证国内数据系统接入功能的完整性、正确性和性能，确保能够稳定获取A股市场数据并满足后续回测系统的需求。

## 2. 测试范围

| 模块 | 测试内容 | 重点验证 |
|------|----------|----------|
| 数据获取API | `get_cn_stock_prices()`, `get_cn_stock_info()`, `get_cn_financial_data()`, `get_cn_stock_list()`, `get_cn_index_prices()` | 数据完整性、格式正确性、异常处理 |
| 数据清洗模块 | 缺失值填充、异常值检测、价格逻辑验证、代码标准化 | 清洗效果、质量报告生成 |
| 数据缓存系统 | 内存缓存、持久化缓存、缓存过期机制 | 缓存命中率、过期策略、缓存管理 |
| API接口 | FastAPI路由 `/cn/prices/{symbol}`, `/cn/info/{symbol}`, `/cn/financials/{symbol}`, `/cn/stocks`, `/cn/index/{symbol}` | 接口响应、参数验证、错误处理 |

## 4. 测试执行计划

### 4.1 测试环境

- 操作系统：macOS
- Python版本：3.9+
- 依赖：akshare, pandas, fastapi, uvicorn
- 测试工具：pytest, httpx, locust

### 4.2 测试步骤

1. **单元测试执行**：运行现有测试用例，确保基础功能正常
   ```bash
   pytest tests/test_cn_data.py -v
   ```

2. **集成测试执行**：添加并运行集成测试用例
   ```bash
   pytest tests/test_cn_data.py::TestCNDataIntegration -v
   ```

3. **API接口测试**：启动后端服务并测试API接口
   ```bash
   # 启动后端服务
   cd app/backend
   uvicorn main:app --reload --port 8000
   
   # 使用httpx测试API
   python -m pytest tests/test_api_integration.py -v
   ```

4. **性能测试**：使用locust进行性能测试
   ```bash
   # 使用locust测试
   locust -f tests/locustfile.py
   ```

5. **边界测试**：手动测试边界条件

| 测试数据不一致 | 使用固定日期范围进行测试，记录测试时间点 |
| 性能测试环境差异 | 使用同一环境进行所有测试，记录环境配置 |
